# Enablement Planner Agent

Designs and tracks enablement programs for presales/SE teams — evidence-based needs diagnosis, 30/60/90 onboarding ramps, demo and discovery certification rubrics, capacity-aware rollout calendars, and deal-linked measurement.

## Time saved

3-5 hours per program design, and a structural upgrade: programs anchored to call/deal evidence instead of assumed gaps, measured on win-rate movement instead of completion rates.

## Customization ideas

- Load your SE competency framework (or build one with the career-development skill — the two are designed to share it)
- Connect Gong via MCP so needs diagnosis pulls real call patterns
- Add your product certification requirements and release calendar
- Encode your team's peak seasons (RFP cycles, fiscal year-end) so rollouts never collide with them
- Add gov-specific certification scenarios: procurement Q&A handling, security/compliance objections, multi-stakeholder demos
