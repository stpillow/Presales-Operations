# Proposal Manager — Cowork Prompt

```
Help me manage our response to this government solicitation.

## The Solicitation
Type: [RFP / RFI / RFQ]
Solicitation number: [Number]
Issuing entity: [Agency / municipality / state]
Submission deadline: [Date, time, timezone]
Q&A deadline: [Date — or "unknown"]
Contract vehicle: [State term / NASPO / Sourcewell / open — or "unknown"]

[Paste the solicitation text or attach the document]

## Our Position
How we learned about it: [Pre-RFP engagement / RFI response / saw it at release]
Incumbent: [Who currently holds this work, or "none/unknown"]
Our fit: [Rough sense of how well we meet the requirements]
Competitors likely bidding: [Names, or "unknown"]

## What I need
1. **Shred it:** Key dates, submission mechanics, evaluation criteria and weights, and every mandatory requirement.
2. **Bid/no-bid scorecard:** Be honest — if we're column fodder for a wired deal, say so.
3. **Compliance matrix:** Every "shall/must" mapped to a section reference, owner, and status.
4. **Win themes:** 3-5 themes tied to how evaluators will actually score, with proof points.
5. **Response calendar:** Backward-scheduled from the deadline with Pink/Red/Gold review gates.

## Rules
- Never claim compliance or certifications we haven't confirmed — mark them "needs SME confirmation."
- Cite the exact solicitation section for every requirement.
- No contact with evaluators outside the official Q&A process.
- Build in a submission buffer — never plan to submit in the final hour.
```
