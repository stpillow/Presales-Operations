# Proposal Manager Agent

Manages a government RFP/RFI/RFQ response end to end — solicitation shredding, bid/no-bid scorecard, compliance matrix, win themes, color-team review calendar, and submission checklist. Shipley-informed, sized for 3-6 week SLG/SLED turnarounds.

## Time saved

4-8 hours per solicitation on shredding and compliance-matrix setup alone, plus a structured process that prevents the expensive failure mode: a non-compliant submission.

## Customization ideas

- Load your answer library / past responses so drafts reuse approved language
- Add your certifications and compliance posture (StateRAMP, CJIS, SOC 2) so the agent knows what it can claim vs. what needs SME confirmation
- Tune the bid/no-bid weights to your team's calibration history
- Connect Salesforce via MCP to auto-pull opportunity and relationship history
- Add your standard color-team reviewer roster
