# Career Development Agent

Builds dual-track (IC + management) career ladders, competency frameworks with behavioral anchors, individual development plans, and evidence-based promotion cases for presales/SE teams.

## Time saved

Days of framework drafting compressed to a working session, and IDPs that take 20 minutes instead of getting skipped — plus better retention economics: SEs with a visible path stay.

## Customization ideas

- Load your existing leveling docs or HR competency framework so outputs align with company language
- Add your org's actual level names and comp-band references
- Share it with the enablement-planner skill — they're designed to use the same competency framework
- Add gov-domain competencies specific to your market (procurement fluency, security/compliance depth)
- Encode your HR calendar (review cycles, calibration windows) so IDPs and promotion cases land on time
