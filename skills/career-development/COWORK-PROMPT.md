# Career Development — Cowork Prompt

```
Help me with career development for my presales team.

## What I need
[Pick one: "Build a career ladder for the team" / "Build an IDP for someone" / "Assemble a promotion case" / "Help someone decide between IC and management tracks"]

## The Team / Person
Team structure: [Levels and roles today, e.g., Associate SC → Principal SC, team of N]
Existing frameworks: [Paste leveling docs or competency frameworks, or say "none — starting fresh"]

If this is about an individual:
Current level: [Level] | Target: [Level]
Evidence of their work: [Deals contributed to, pursuits led, demo certifications, call feedback, manager observations — the more specific the better]

## What good looks like
1. Competencies with **behavioral anchors** — observable behaviors, not adjectives like "strong communicator."
2. IC and management tracks treated as equally valuable.
3. Development plans weighted toward real experiences (stretch pursuits, review leadership) over courses.
4. Everything drafted for MY review as the manager — not written to be forwarded straight to the employee.

## Rules
- Rate only on evidence I've given you. If you don't have evidence for a competency, mark it "insufficient evidence" and tell me what to observe.
- No compensation recommendations.
- Don't compare named people against each other.
- Note that promotions still run through our HR/calibration process — this prepares the case, it doesn't decide it.
```
